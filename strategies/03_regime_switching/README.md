# 03. マクロ連動・レジームスイッチング (Macro Regime Switching) 戦略

## 1. 戦略概要
「強気相場では買いのみ、危機・急落相場では空売りのみ」へと市場レジーム（VIX指数・SOX前日騰落率）に応じて売買方向を100%完全スイッチングする全天候型戦略。

---

## 2. レジーム判定ロジック
* 🟢 **強気相場 (Risk-On / VIX <= 21 かつ SOX >= -1.5%)**:
  - 買い（Long）のみを執行。空売りは完全禁止（踏み上げリスクをゼロ化）。
* 🔴 **危機相場 (Risk-Off / VIX > 21 または SOX < -1.5%)**:
  - 買いを全面停止。空売り（Short）のみを執行。

---

### 💡 クオンツ的発見（寄り底の罠とギャップダウン）
* **「SOX急落を見て翌朝寄付で空売りする」と大敗する理由**:
  * 米国の急落は、日本市場の寄り付き（Open）の段階ですでにギャップダウン（窓開け安寄り）として織り込まれる。
  * 最安値で空売りを建てさせられた後、市場が「自律反発（押し目買い）」に向かうため、踏み上げ損切りを食らう。
  * $\rightarrow$ **「下落相場では無理に空売りを狙わず、ノーポジション（全額キャッシュ）で待機するのが最も安全」** という教訓を確立。
