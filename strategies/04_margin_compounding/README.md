# 04. 信用レバレッジ ＆ 益出し複利 (Margin Compounding) 戦略

## 1. 戦略概要
日本の著名投資家（STF氏等）が実践した「信用取引での益出し（利確した利益を保証金に算入し、次の建て玉枠を雪だるま式に拡大する）」の手法をクオンツモデル化。
マクロ指標（VIX・SOX）に応じて新規定率レバレッジ枠を動的にコントロールする高回転・高収益戦略。

---

## 2. コアルール
1. **益出し複利**:
   - 3日保有スイングで利確した確定利益はすべて「純資産（保証金）」に即時算入され、次回の最大建て玉枠（$\text{純資産} \times \text{レバレッジ倍率}$）を拡大。
2. **新規枠の動的マクロ制御**:
   - 🟢 強気時 (VIX <= 16, SOX > 0): **レバレッジ 2.5〜3.0倍 (全力益出し)**
   - 🟡 警戒時 (18 < VIX <= 21): **レバレッジ 1.0〜1.2倍**
   - 🔴 危機時 (VIX > 21): **新規買い停止（ノーポジションへ自然移行）**
3. **コスト体系**: 買方金利（年利 2.8%）＋ 往復スリッページ手数料（0.1%）を厳密控除
