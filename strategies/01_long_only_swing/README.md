# 01. 現物ロング・3日スイング戦略 (Long Only Swing - Baseline)

## 1. 戦略概要
東証主要銘柄を対象に、テクニカル指標と海外マクロ指標を組み合わせたLightGBM Meta-labelingモデルを用いて高勝率な銘柄を厳選し、3営業日保有して利益を刈り取る現物買いスイングトレード戦略（本システムの基準ベースライン）。

---

## 2. 売買ロジックと執行フロー
1. **銘柄スクリーニング＆特徴量**:
   - テクニカル: 5日/20日SMA乖離率, ATR(14), 直近出来高サージ率
   - 海外マクロ (前日Lag 1): SOX指数騰落率, S&P500騰落率, ドル円為替変動, 米10年債利回り, VIX指数
2. **Meta-labeling推論**:
   - 前日引け後に全銘柄の勝率確率 $P(\text{Win})$ を推論
   - $P(\text{Win}) > 0.55$ の高確信度銘柄を抽出
3. **エントリー**: 翌営業日 寄付（Open）成行買い
4. **エグジット**: エントリーから 3営業日後の大引け（Close）成行決済
5. **資金管理**: 5銘柄分散（各20%アロケーション）、レバレッジ1.0倍（現物）、単元未満株（1株単位）
