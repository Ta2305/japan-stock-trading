# 02. 信用取引・空売り統合 (Credit Long & Short) 戦略

## 1. 戦略概要
下落トレンドや地合い悪化局面でも利益を狙うため、信用取引を用いた空売り（Short / 制度信用取引・レバレッジ1.0倍）を買い（Long）シグナルと統合した双方向売買戦略。

---

## 2. 売買ロジック
1. **買い（Long）**: SMAゴールデンクロス＋出来高急増＋マクロ追い風 $\rightarrow$ 翌日寄付成行買い $\rightarrow$ 3日後引け返済売り
2. **空売り（Short）**: SMAデッドクロス＋出来高急増＋安値ブレイク＋マクロ逆風（SOX急落・VIX急騰） $\rightarrow$ 翌日寄付信用新規売り $\rightarrow$ 3日後引け返済買い
3. **コスト体系**: 往復スリッページ手数料 0.1% ＋ 信用貸株料（年1.15% = 日歩 約0.003%）控除

---

## 3. バックテスト検証実績 (2026年 Out-of-Sample)

| 項目 | 5分散 × 3日保有 | Top集中 × 3日保有 |
| :--- | :---: | :---: |
| **最終資産** | **¥1,549,973** | ¥825,790 |
| **累積リターン** | **+55.00% (1.55倍)** | -17.42% |
| **勝率** | **49.5%** (Long 101回 / Short 101回) | 47.5% |
| **最大ドローダウン** | **-46.30%** | -43.89% |

### 💡 クオンツ的考察
* **7月暴落時のヘッジ効果**: 2026年7月のSOX急落相場単体で見れば、空売りによって資産が +23% 増加しヘッジとして機能した。
* **踏み上げ（Short Squeeze）リスク**: 強い上昇トレンドの途中で一時的な陰線で空売りを入れると、直後の急反発で大きな損切りを被るため、常時空売りを探すのはドローダウンが拡大する（Max DD -46%）。
