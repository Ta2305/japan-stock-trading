# 05. Alpha-Max 最強モメンタム集中 ＆ 動的信用レバレッジ戦略

## 1. 戦略概要
これまでのすべての研究成果を結集した最高峰の全天候型クオンツ戦略。
「Point-in-Time モメンタム複合スクリーニング」で最強銘柄（Top 2〜3銘柄）に資金を集中させ、「市場25日線 ＆ VIX連動レバレッジ（最大2.5倍）」と「ブレークイーブン・トレイリング防御」を組み合わせて大相場を捉えながらドローダウンを極小化。

## 2. コア・イノベーション
1. **モメンタム複合スコア (大口資金流入の特定)**:
   $$\text{Score} = (\text{出来高サージ} \times 0.45) + (\text{ATR拡大率} \times 0.35) + (\text{高値近接度} \times 0.20)$$
2. **市場トレンド＆マクロ連動レバレッジ**:
   - 🟢 日経/TOPIX > 25日線 かつ VIX < 18: **レバレッジ 2.0〜2.5倍**
   - 🟡 日経/TOPIX > 25日線 だが VIX 18〜21: **レバレッジ 1.0倍**
   - 🔴 市場 < 25日線 または VIX > 21: **レバレッジ 0倍 (全額キャッシュ退避)**
3. **ブレークイーブン・トレイリング防御 (利益確約)**:
   - 保有中に $+1.5\text{ATR}$（急騰）を達成した瞬間に、逆指値（SL）を買値（同値）以上に引き上げ、損失転落を100%防止。
4. **Walk-Forward ローリング最適化**:
   - 毎年直近3年間の最新データでLightGBMモデルを自動再学習。
